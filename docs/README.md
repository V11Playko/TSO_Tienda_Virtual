## Convenciones
- Un acta por reunión dentro de `actas/`, con nombre `acta-AAAA-MM-DD.md`. Desde la entrega 2 las reuniones se reportan como **lanzamientos**.
- Cada integrante actualiza LOGT y LOGD el mismo día que trabaja.
- El estado semanal se copia como `WEEK-semana-N.md` dentro de `seguimiento/`.
